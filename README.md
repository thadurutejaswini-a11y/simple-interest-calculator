 # Simple Interest Calculator

## Description

This project is a simple calculator that computes simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Features

- Calculate simple interest quickly and accurately.
- Easy-to-use interface.
- Lightweight and beginner-friendly project.

## Usage

1. Enter the principal amount.
2. Enter the rate of interest.
3. Enter the time period.
4. Click the Calculate button.
5. View the calculated simple interest.

- HTML
