# Code of Conduct

## Our Pledge

We are committed to making participation in this project a respectful and harassment-free experience for everyone.

## Expected Behavior

- Be respectful and considerate.
- Use welcoming and inclusive language.
- Accept constructive feedback gracefully.
- Focus on what is best for the project and community.

## Unacceptable Behavior

- Harassment, discrimination, or offensive comments.
- Personal attacks or insults.
- Trolling or deliberately disruptive behavior.
- Publishing private information without permission.

## Enforcement

Project maintainers are responsible for clarifying and enforcing these standards. They may remove, edit, or reject comments, commits, code, or other contributions that violate this Code of Conduct.

## Scope

This Code of Conduct applies to all project spaces, including GitHub issues, pull requests, discussions, and other communication channels related to this project.

## Contact

If you experience or witness unacceptable behavior, please contact the project maintainer through GitHub.
